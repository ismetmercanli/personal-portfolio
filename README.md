## 📖 About

This is a single-page portfolio site built to present my education, ongoing projects, and career goals in one place. It includes sections for an introduction, education timeline, project showcase (with GitHub links), goals, and areas of interest — with support for both Turkish and English.

## ✨ Features

- 🌐 Multi-language support (Turkish / English)
- 📱 Fully responsive design
- 🗂️ Project showcase with GitHub links
- 🎯 Education and goals sections
- ⚡ Fast, statically optimized pages via Next.js

## 🛠️ Tech Stack

- **Next.js** – React framework
- **React** – UI library
- **CSS / Tailwind** *(update based on actual styling setup)*

## 🚀 Getting Started

Clone the repository and run it locally:

\`\`\`bash
# Clone the repository
git clone https://github.com/ismetmercanli/<repo-name>.git

# Move into the project directory
cd <repo-name>

# Install dependencies
npm install

# Start the development server
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.
